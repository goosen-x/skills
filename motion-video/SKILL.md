# Motion video

Ролик — это программа: одна функция `seek(t)` рисует любой момент времени, headless Chromium снимает кадры, ffmpeg собирает MP4. Промпт решает 10% результата, остальное делают референс, реальные материалы и цикл критики по кадрам.

## Старт

```bash
bash <skill-dir>/scripts/new-project.sh ~/Documents/<имя-ролика>
```

Шаблон кладёт в папку движок, плеер, скрипты и `CLAUDE.md` с правилами рендера. Прочитай этот `CLAUDE.md` до первой сцены. Каждый новый ролик делается в отдельной папке.

## Процесс (этапы по порядку, не пропускать)

1. **Входные данные.** Спроси: о чём ролик и где он будет показан, формат (16:9 / 9:16 / 1:1), длительность, референс (видео, кадр, ссылка), музыка (файл или «синтезировать»), бренд (цвета, шрифты, логотип). Проекты и сайты ищи сначала локально.
2. **Референс.** Кадры раз в 0,5 с в контакт-лист: `ffmpeg -i ref.mp4 -vf "fps=2,scale=480:-1,tile=4x6" -frames:v 1 refs/sheet.png`. Посмотри его, выпиши темп, типографику, переходы и приёмы камеры. Бери грамматику, не содержимое.
3. **Музыка и сетка.** `beats.py` → `beats.json`. Сцены ставятся на сильные доли: `DROP + n * BAR`. Своя музыка без прав: синтез в коде по той же сетке.
4. **Материалы.** Сайты: `node shoot.mjs <url> <name>` (+ `--mobile`). Интерфейсы, где нужно вводить текст и нажимать кнопки: `node snapshot.mjs <url> <name> [--state session.json]` и `liveFrame` в сцене. Личные данные в кадре заменяй выдуманными.
5. **Шот-лист** на сетке трека: что происходит в каждой сцене и на какой доле клик или склейка. Покажи его пользователю до кода.
6. **Сцены** в `index.html` через API ниже.
7. **Критика.** `npm run stills -- --step 0.5`, открыть `out/contact.png`, оценить, исправить 3 худшие проблемы, повторить. Точечно: `--from 8 --to 11 --step 0.1`.
8. **Рендер** `npm run render` (около 12 с на секунду ролика при 60 fps), запускать в фоне. Проверить кадры уже из MP4.

## API движка (`engine.js`)

| Функция | Для чего |
|---|---|
| `scene(from, to, {bg, grid})` | сцена; задать `s.update = (u) => …`, где `u` — локальное время |
| `sp(u, t0, k, d)`, `track(u, keys, k, d)` | пружина с момента t0; значение с несколькими целями |
| `eio`, `eo`, `lerp`, `clamp`, `rng(seed)` | кривые, интерполяция, детерминированный шум |
| `letters(parent, text, css)` | текст по буквам, анимировать `inner[i]` |
| `cropFrame`, `browserCard`, `macbook`, `iphone` | рамка с уголками, окно браузера, устройства devices.css |
| `liveFrame(parent, name, css, setup)` | живая страница из `snapshot.mjs`, DOM доступен в `setup(doc)` |
| `cursor(parent)` | курсор и кольцо клика |
| `start(DUR, extraImages)` | вызвать один раз в конце, создаёт `seek` и `ready` |

Просмотр: `npm run preview` → http://localhost:5173 (пробел, ←/→ по кадрам, звук из `window.AUDIO_URL`).

## Частые ошибки

| Симптом | Причина и решение |
|---|---|
| В начале сцены пустой кадр или рывок на склейке | вход начинается в момент склейки; сдвинь старт пружины в минус: `sp(u, -.12, …)` |
| Белые пустые блоки на скриншоте | lazy-load; `shoot.mjs` прокручивает страницу до съёмки, GIF замораживать в кадр |
| В кадре плашка cookie, чат, значок Next.js | `shoot.mjs` и `snapshot.mjs` их вырезают; проверить глазами |
| Вырезанный кусок скриншота «ломается» при анимации | собрать элемент заново в HTML с реальными стилями сайта |
| Нужен экран за логином | окно Playwright с `headless: false`, пользователь входит сам, сохранить `storageState` |
| Кнопка без контекста читается как предложение студии | сначала показать сайт, потом клик |
| Сайт не открывается (таймаут) | повторить позже или взять из локального проекта: поднять dev-сервер на пустой локальной БД |
| Анимация остановилась, картинка стоит | в конце каждой сцены медленный наезд `scale(1 + .05 * eio(...))` |
| Нет звука в превью | браузер разрешает звук только после клика; `.m4a` грузить как blob с типом `audio/mp4` |
