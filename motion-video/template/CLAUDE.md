# Motion video: правила проекта

## Контракт рендера
- Весь ролик — чистая функция времени: `window.seek(t)` рисует кадр t. Никаких CSS-transition, `setTimeout`, `requestAnimationFrame` в сценах, никакого состояния между кадрами.
- Случайность только через `rng(seed)`, никогда `Math.random`.
- Движение через пружины `sp()`/`track()` и кривые `eio`/`eo` из `engine.js`, не через линейный `lerp` по времени.
- Реальный контент (сайты, приложения): живая вёрстка через `snapshot.mjs` + `liveFrame`, либо скриншоты через `shoot.mjs`. Интерфейсы не рисовать «по памяти».

## Запрещённые дефолты
- Заголовок по центру на градиенте, всё появляется через fade-in, подписи в углах кадра, глоу на UI, случайные частицы.
- Пустые или статичные кадры: каждые 2–4 секунды что-то новое, в конце каждой сцены медленный наезд.

## Звук
- Склейки на сильных долях: `beats.py` → `beats.json`, сцены ставить на `DROP + n * BAR`.
- Громкость финала −14 LUFS (делает `render.mjs`).

## Прежде чем показывать
1. `npm run stills -- --step 0.5` и посмотреть `out/contact.png` глазами.
2. Оценить 1–10: крючок в первые 2 с, читаемость на телефоне, качество движения, разнообразие, попадание в бренд, синхрон со звуком.
3. Исправить 3 худшие проблемы. Повторять, пока все оценки не 8+.
4. Только потом `npm run render`.
